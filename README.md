# Five

A tiny, single-page focus timer. Five-minute rounds, a circular progress ring, and a running count of rounds completed today.

## Usage

Open `index.html` in a browser — no build step or server required.

- Click the ring (or press `Space`) to start/pause a round
- **Reset** clears the current round back to 5:00
- A chime plays when a round completes, and the day's round count is saved locally in the browser
- Use the toggle in the top-right corner to switch between light and dark themes

## Files

- `index.html` — markup
- `main.css` — styling and theme variables
- `main.js` — timer logic, round tracking, and theme toggle
